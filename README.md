# Smooth-Cookie

**Reclaim user agency over consent: automate "Necessary Only" across the web.**

Smooth-Cookie is an open-source project that aims to automate choosing the minimal-consent option ("Necessary only" or equivalent) on consent banners, so users can avoid the cognitive load and dark patterns that push toward "Accept all."
